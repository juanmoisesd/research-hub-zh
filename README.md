## 🧬 Semantic Infrastructure

This repository includes a multilingual semantic layer for Chinese-Western scientific alignment:

| File | Description |
|------|-------------|
| [`semantic/cn-academic-keywords.json`](semantic/cn-academic-keywords.json) | ES/EN/ZH-Hans/ZH-Hant academic keyword ontology with MeSH IDs |
| [`semantic/neuro-ontology-zh.json`](semantic/neuro-ontology-zh.json) | Neuroscience concepts with ZH-Hans/ZH-Hant disambiguation |
| [`ontology/mesh-zh-alignment.json`](ontology/mesh-zh-alignment.json) | 15 MeSH terms aligned to ZH-Hans and ZH-Hant with UMLS, SNOMED CT, ICD-11 |

> **Note on Chinese normalization:** This repository distinguishes between zh-Hans (Simplified, mainland China) and zh-Hant (Traditional, Taiwan). These differ in character encoding, tokenization, and in some cases cultural meaning (e.g., dementia: 痴呆 vs 失智症).
